# Repo notes

- Exported from the claude.ai StreamKeepr design-system artifact (MudBlazor 9.12.0, colourful dark theme, Roboto) on 2026-11-15. It replaces the earlier Dracula PRO export.
- **This directory is authoritative** (ADR 0012). Design changes are PRs here; the claude.ai artifact is re-synced from the repo and marked as synced from code, never edited directly.
- Changes made on import:
  - `streamer-1` … `streamer-8` and `streamer-contrast-text` are renamed `channel-*` (glossary: **Channel colour**).
  - `type.groups[].styles[button]` carries `"textTransform": "none"`, the one typography override, so the theme test can check it.
  - Roboto is one self-hosted variable font subset to Latin, not four static weights; `mudblazor-theme.md` says so.
  - The previews' Google Fonts links are removed. In the repo, previews are markup references: the artifact supplies their tokens, `bundle.css` and font.
  - The `assets/` READMEs are not imported; the logo and favicon set lives in `branding/`.
- `tokens.json` feeds `src/StreamKeepr/Ui/StreamKeeprTheme.cs` (checked by `StreamKeeprThemeTests`) and `src/StreamKeepr/wwwroot/css/tokens.css` (generated by `scripts/build-tokens.mjs`, checked by `tests/js/tokens.test.js`).
- `fonts/` held Material Symbols Rounded (Apache-2.0) until the cleanup slice (#181) removed it with the app's last ligature icon; the system has no font files of its own.
